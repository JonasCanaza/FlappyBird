# Flappy Bird

A **Flappy Bird** game developed in **C++** using **BorjaLib**, which includes a **local multiplayer** mode for two players on the same machine.

## Features

- Classic Flappy Bird gameplay
- Local multiplayer (2 players on the same machine)
- Sound effects and background music
- Clean and modular C++ code

## Tools Used

- **Framework/Engine:** [BorjaLib](https://github.com/BorjaLia/Borja_Lib)
- **Language:** [C++](https://isocpp.org/std/the-standard)
- **Development environment:** [Visual Studio](https://visualstudio.microsoft.com/es/)
- **Image creation and editing:** [Geometry Dash](https://www.robtopgames.com/), [GIMP](https://www.gimp.org/downloads/), [Canva](https://www.canva.com/)
